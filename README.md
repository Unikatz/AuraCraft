# Aura Isles

A cozy building game on floating islands in the sky, designed from a 10-year-old's ideas. It runs in any modern browser on a computer, tablet or phone.

This branch is the redesign of Aura Craft (see the v2-beta and v1-stable branches for earlier versions).

## What's in it
- Seven sets of floating isles joined by rainbow bridges: Meadow, Frost, Sunsand, Ember, Sweet, Art and Funfair
- Toy-like rounded blocks with ink outlines; a third-person character with an aura ring that grows with your rank
- Isle Folk (Gardener, Inventor, Toy Maker, Baker, Star Sage) who run shops in each isle's town
- Original creatures: Puff-sheep, Mochi-moos, Berry-pigs, Bounce-buns, Star-chicks, Pan-pals, Snow-pips and Dune-loafs
- Gloomies: shadow puffs you calm with light, not fight. Fizz Pops burst into confetti and coins. Party Poppers clear blocks with confetti
- Dream Pods, bounce pads, Doggy and Mew as bodyguards, aura farming, the 6 7 move
- A cloud catches you if you fall off an island
- A 20-step quick guide with a step-by-step house builder

## Controls (computer)
WASD move · mouse look · left click break · right click place · Space jump (hold at a wall to climb) · Shift run · E use · T torch · V camera · R go home · F aura farm · Q blocks · C craft · B shop · M isles · G guide · H help

## Run it
A single static page: open `index.html` in a browser, or deploy the folder to any static host. three.js loads from cdnjs. Progress is saved in the browser (localStorage).
